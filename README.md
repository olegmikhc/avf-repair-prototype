# AVF Group — ремонтное направление

Интерактивный прототип сайта: семь услуг, примеры объектов, информация о компании и демонстрационная форма.

Статический сайт без зависимостей в `docs/`. Откройте `docs/index.html` в браузере для локального просмотра.

GitHub Pages публикует папку `/docs` ветки `main`. Изменения автоматически обновляют сайт.

Контакты и фотографии пока не добавлены. Форма не отправляет и не сохраняет данные. Знак бренда схематичный, для прототипа.
